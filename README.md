# Reyes golf course hearing timeline

An hour-by-hour timeline of the October 19, 2026 evidentiary hearing before Judge Ana Reyes in *DC Preservation League v. Department of the Interior*. It is compiled from the live-blog thread by Roger Parloff for Lawfare, and every entry links back to the original Bluesky post.

- Read it: [index.md](index.md), or the GitHub Pages site.
- Original thread: https://bsky.app/profile/rparloff.bsky.social/post/3myaamheol22p

The dialogue is Parloff's real-time paraphrase, not a court transcript.
